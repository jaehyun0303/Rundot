# Rundot

쿠키런: 오븐브레이크 방식의 2D 도트 횡스크롤 러너 게임. 판타지 숲의 소동물 모험단이 달린다.

## 실행

ES 모듈이나 빌드 도구 없이 순수 JavaScript + Canvas로 만들었다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

`index.html`을 직접 더블클릭해서 열어도 실행된다.

## 조작

| 동작 | 키보드 | 터치 |
|---|---|---|
| 점프 / 2단 점프 | Space, ↑, W | 화면 오른쪽 절반 |
| 슬라이드 | ↓, S (누르고 있기) | 화면 왼쪽 절반 (누르고 있기) |
| 히트박스 보기 | B | - |

## 규칙

- 체력은 시간이 지나면 계속 줄어든다. 하트를 먹으면 회복된다.
- 기둥은 점프로, 매달린 통나무는 슬라이드로 피한다. 부딪히면 체력이 깎인다.
- 구멍에 빠지거나 체력이 0이 되면 끝난다.
- 스킬 게이지가 다 차면 스킬이 자동으로 발동한다.
- 아이템: 무지개 별 = 부스트(무적, 가속), 보라 구슬 = 자석

## 캐릭터

| 캐릭터 | 스킬 |
|---|---|
| 여우 견습기사 | 돌진: 빨라지고 장애물을 부순다 |
| 고양이 마법사 | 자석 마법: 아이템을 끌어당긴다 |
| 곰 대장장이 | 거대화: 커져서 장애물을 부순다 |
| 토끼 도적 | 3단 점프 + 점수 2배 |
| 부엉이 비행사 | 비행: 점프를 누르고 있으면 난다 |

## 구조

```
index.html              진입점
src/data.js             밸런스 값, 캐릭터·아이템·장애물 정의
src/sprites.js          임시 도트 캐릭터 (코드로 그림)
src/game.js             게임 로직 (물리, 맵 생성, 충돌, 스킬)
src/render.js           화면 그리기
src/main.js             화면 전환, 입력, 게임 루프
assets/raw/             AI로 생성한 원본 이미지
assets/game/            게임에서 쓰는 가공된 PNG
tools/process_assets.py 원본 → 게임용 PNG 변환 (배경 제거, 자르기)
```

## 에셋 작업

```bash
python3 tools/process_assets.py
```

- 새 이미지는 `#FF00FF` 마젠타 배경으로 생성해서 `assets/raw/`에 넣고, `CROPS` 표에 `"magenta"` 모드로 추가한다.
- 캐릭터는 아직 코드로 그린 임시 도트(`src/sprites.js`)다. 진짜 스프라이트 시트가 생기면 `RD.getCharacterFrame`이 PNG 프레임을 돌려주도록 바꾸면 된다.
