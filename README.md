# Rundot

텐가이, 1945 같은 오락실 2D 도트 슈팅 게임. 판타지 숲의 소동물 모험단이 가로로 흘러가는 숲 위를 날며 몬스터 편대와 탄막을 뚫고 보스를 잡는다.

## 실행

ES 모듈이나 빌드 도구 없이 순수 JavaScript + Canvas로 만들었다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

## 조작

| 동작 | 키보드 | 터치 |
|---|---|---|
| 이동 | 방향키, WASD | 화면 아무 데나 대고 끌기 (끈 만큼 움직임) |
| 정밀 이동 | Shift (누르고 있기) | - |
| 사격 | 자동 | 자동 |
| 폭탄 | X, Space, K | 오른쪽 아래 원 (세로 화면은 폭탄 버튼) |
| 히트박스 보기 | B | - |

## 규칙

- 캐릭터 가운데의 **빨간 점**에 탄이나 적이 닿으면 잔기가 하나 줄어든다. 그림에 스쳐도 점만 피하면 안 맞는다.
- 잔기 3개로 시작, 10만 점마다 1개 추가. 모두 잃으면 게임 오버.
- **P** 아이템: 파워업 (최대 4단계). 편대를 전부 잡거나 도깨비불을 잡으면 나온다. 죽으면 파워 1 감소.
- **B** 아이템: 폭탄 +1 (최대 5개). 폭탄은 화면의 적 탄을 지우고 적 전체에 피해, 잠깐 무적.
- 파워 2부터 펫 슬라임이 같이 쏜다 (파워 4면 2발).
- 코인, 보석, 별은 점수. 가까이 가거나 화면 오른쪽 끝으로 가면 끌려온다.
- 스테이지: 약 37초에 중간 보스(돌 골렘), 약 73초에 보스(박쥐 왕). 보스를 잡으면 더 어려운 다음 주차로 다시 시작한다 (적 체력 +60%, 탄속 +12%).

## 적

| 적 | 움직임 | 공격 |
|---|---|---|
| 박쥐 | 편대로 날아옴 (물결, 직선, 돌진) | 조준탄 1발 |
| 도깨비불 | 날아와서 잠시 멈춤 | 원형 탄막 |
| 슬라임 | 땅에서 통통 뜀 | 조준탄 |
| 독버섯 | 땅에 서 있음 | 3갈래 탄 |
| 돌 골렘 (중간 보스) | 땅에서 버팀 | 부채꼴 탄, 바위 포탄 |
| 박쥐 왕 (보스) | 위아래로 움직임 | 체력에 따라 3단계: 부채꼴+박쥐 소환 → 나선 탄막 → 원형 탄막+고속탄 |

## 캐릭터

| 캐릭터 | 타입 | 샷 | 폭탄 |
|---|---|---|---|
| 여우 견습기사 | 관통형 | 검기 (적을 뚫고 나감) | 일섬 |
| 고양이 마법사 | 유도형 | 유도 마법 구슬 | 별빛 마법진 |
| 곰 대장장이 | 강타형 | 쇠망치 탄 (느리지만 강함) | 대지 강타 |
| 토끼 도적 | 연사형 | 단검 난사 | 그림자 단검 폭풍 |
| 부엉이 비행사 | 확산형 | 바람 깃털 (부채꼴) | 회오리 바람 |

## 밸런스 조절

숫자는 대부분 `src/data.js`에 있다.

- `RD.CONFIG`: 이동 속도, 피격 판정 크기(`hitRadius`), 잔기, 폭탄, 터치 감도
- `RD.CHARACTERS[].shot`: 샷 간격(`cd`), 위력(`dmg`), 파워별 탄 배치(`lanes`)
- `RD.ENEMIES`: 적 체력과 점수
- `RD.BULLET.speed`: 적 탄속
- 등장 순서와 시간은 `src/game.js`의 `STAGE` 표, 적 탄막 패턴은 `updateEnemies`

회피 봇으로 시뮬레이션했을 때 파워 4 기준 중간 보스 약 6초, 보스 약 40~50초 걸린다.

## 구조

```
index.html              진입점
src/data.js             밸런스 값, 캐릭터·적·아이템 정의
src/sprites.js          임시 도트 캐릭터와 몬스터 (코드로 그림)
src/game.js             게임 로직 (스테이지 진행표, 적 패턴, 탄, 아이템, 폭탄)
src/render.js           화면 그리기
src/main.js             화면 전환, 입력, 게임 루프
assets/raw/             AI로 생성한 원본 이미지
assets/game/            게임에서 쓰는 가공된 PNG
tools/process_assets.py 원본 → 게임용 PNG 변환 (배경 제거, 자르기)
```

## 에셋 작업

```bash
python3 tools/process_assets.py
```

- 새 이미지는 `#FF00FF` 마젠타 배경으로 생성해서 `assets/raw/`에 넣고, `CROPS` 표에 `"magenta"` 모드로 추가한다.
- 캐릭터는 아직 코드로 그린 임시 도트(`src/sprites.js`)다. 진짜 스프라이트 시트가 생기면 `RD.getCharacterFrame`이 PNG 프레임을 돌려주도록 바꾸면 된다.
