# Rundot

텐가이, 1945 같은 오락실 2D 도트 슈팅 게임. 판타지 숲의 소동물 모험단이 가로로 흘러가는 숲 위를 날며 몬스터 편대와 탄막을 뚫고 보스를 잡는다.

## 실행

ES 모듈이나 빌드 도구 없이 순수 JavaScript + Canvas로 만들었다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

## 지역 (스테이지)

| 지역 | 지형 효과 | 보스 | 보스 특성 | 특수 몬스터 |
|---|---|---|---|---|
| 1. 속삭이는 숲 | 숲의 축복: 하트 2배 | 박쥐 왕 | 흡혈 (탄에 맞으면 회복), 분노 시 빨라짐 | 치유 요정, 자폭 가시공 |
| 2. 수정 동굴 | 어둠: 내 주변만 보임 (적 탄은 보임) | 수정 거인 | 수정 갑옷: 도는 수정 4개가 있으면 피해 65% 감소 | 저격 눈알, 갑옷 딱정벌레 |
| 3. 불타는 화산 | 용암 분출: 예고 후 용암 기둥, 불똥 | 마그마 슬라임 왕 | 뛰었다 착지하며 탄과 용암 자국, 새끼 슬라임 소환 | 자폭 가시공, 갑옷 딱정벌레 |
| 4. 얼어붙은 설원 | 빙판(미끄러짐)과 강풍 | 서리 여왕 | 빙결: 탄에 맞으면 느려짐, 빈틈 있는 고드름 벽 | 딱정벌레, 요정, 눈알 |
| 5. 폭풍의 하늘 | 낙뢰: 예고선 자리에 번개 | 폭풍 군주 | 순간이동, 고속 연속탄 | 눈알, 가시공, 요정 |

- 보스는 체력에 따라 3단계로 패턴이 바뀐다. 중간 보스는 지역 색의 골렘.
- 지역 배경 이미지(`bg_cave` 등)가 `assets/game/`에 없으면 코드로 그린 임시 배경을 쓴다. 이미지를 넣으면 자동으로 바뀐다.
- 몬스터는 지역마다 색이 바뀐다 (`RD.VARIANTS`).

## 보스 공격 패턴

| 보스 | 1단계 | 2단계 | 3단계 (분노) |
|---|---|---|---|
| 박쥐 왕 | 피 방울 부채꼴 + 박쥐 떼 | 빈틈 하나 있는 초음파 고리 | 피의 비 + 박쥐 떼 + 고속 피 방울 |
| 수정 거인 | 날아가다 멈춰 다시 조준하는 수정 조각 | 예고 후 휩쓰는 수정 레이저 2줄 + 수정 비 | 플레이어를 둘러싼 수정 감옥 + 레이저 |
| 마그마 슬라임 왕 | 포물선 용암 덩이 (떨어진 자리에 용암) | 시간차로 터지는 불덩이 | 3갈래 불꽃 나선 + 용암 분출 |
| 서리 여왕 | 퍼졌다 떠다니는 눈꽃 | 빈틈 있는 고드름 벽 / 눈보라 숨결 | 고드름 얼음 감옥 + 눈꽃 |
| 폭풍 군주 | 번개 연속탄 | 예고 후 이어지는 연쇄 번개 + 흩뿌리기 | 플레이어 주위를 돌며 빨려 드는 폭풍 소용돌이 + 낙뢰 |

## 특별 모드

### 🍬 달콤한 꿈
- 사탕 나라 지역. 사탕이 비처럼 내리고 적도 사탕을 떨어뜨린다.
- 사탕을 먹으면 꿈 게이지(체력)가 조금 차고, 30개를 모으면 **슈가 러시** 6초: 무적, 연사 2배, 화면의 적 탄이 사탕으로 바뀐다.
- 잔기 1개 (꿈 게이지가 바닥나면 잠에서 깬다).
- 55초에 젤리 골렘, 약 130초에 **악몽** 보스. 악몽은 사탕 고리가 검게 변해 덮쳐 오고, 잠꼬대 Z를 흘리며, 마지막에는 **조작을 3초 뒤집는다**. 쓰러뜨리면 클리어 (코인 +150).

### 🎺 일곱 나팔 소리의 심판
요한계시록 8~12장의 일곱 나팔 재앙을 바탕으로 했다. 나팔이 약 38초마다 하나씩 울리고, 보스와 천사가 살아 있는 동안은 다음 나팔이 울리지 않는다. 점수 x2.

나팔이 울릴 때마다 **컷씬**: 게임이 멈추고 천사가 내려와 나팔을 불며, 요한계시록 내용을 풀어 쓴 대사가 나온다 (`RD.TRUMPET_SCENES`). 시작할 때는 일곱 천사가 나란히 서고, 다섯째 나팔 전에는 독수리가 "화, 화, 화"를 외친다. 터치 / Space로 넘기고, 건너뛰기 버튼이나 Esc로 건너뛴다.

| 나팔 | 재앙 |
|---|---|
| 첫째 | 피 섞인 우박과 불이 촘촘히 쏟아지고, 땅이 불타는 지대와 불의 소나기 |
| 둘째 | 불붙은 큰 산이 떨어지고 피의 탄이 튄다. 보스 **혼돈의 심판 드래곤** (불붙은 산 던지기 → 피바다 → 모든 재앙을 뒤섞는 혼돈) |
| 셋째 | 큰 별 '쓴 쑥'이 떨어져 독 연기 지대를 남긴다 |
| 넷째 | 해와 달과 별이 어두워지고 달이 핏빛이 된다. 13초마다 **악몽 속**으로 빠졌다가 깨어난다 (조작 반전, 진짜와 가짜가 섞인 탄) |
| 다섯째 (첫째 화) | 무저갱의 연기와 황충 떼, 보스 **무저갱의 사자 아바돈** |
| 여섯째 (둘째 화) | 결박에서 풀린 **네 천사**와 불·연기·유황을 뿜는 마병대 |
| 일곱째 | 번개, 지진, 큰 우박, 그리고 최종 보스 **큰 붉은 용** (일곱 머리에서 쏘는 탄, 꼬리로 끌어내리는 별, 물을 강같이 토하는 벽) |

용을 쓰러뜨리면 클리어 (코인 +300).

## 규칙

- **체력**: 최대 100. 탄에 맞으면 18, 적과 부딪히면 28 깎인다(난이도 배율 적용). 맞은 뒤 0.9초 무적. 체력이 0이 되면 잔기 하나를 잃고 체력을 모두 채워 다시 나온다.
- 판정은 캐릭터 가운데의 **빨간 점**. 그림이 스치는 건 괜찮다.
- **하트**: 체력 30 회복. 적이 가끔 떨어뜨리고, 도깨비불과 보스는 자주 떨어뜨린다.
- **경험치와 레벨업**: 적을 잡으면 경험치가 쌓이고, 레벨이 오르면 게임이 멈추고 **강화 카드 3장 중 하나를 고른다**. 3장 중 하나는 꼭 주무기나 전용 강화다.
- **P**: 경험치 덩어리. 편대를 전부 잡거나 도깨비불을 잡으면 나온다.
- **B**: 폭탄 +1. 폭탄은 적 탄을 지우고 적 전체에 피해, 잠깐 무적.
- 15만 점마다 잔기 +1.

## 캐릭터와 뽑기

여우와 토끼는 처음부터 가지고 있고, 나머지는 **캐릭터 뽑기**로 얻는다.

| 캐릭터 | 등급 | 공격 방식 | 전용 강화 | 궁극기 |
|---|---|---|---|---|
| 여우 견습기사 | 일반 (기본) | **근접 베기**: 앞쪽 부채꼴을 벤다. 파워 3부터 위아래 두 번. 패시브 **베기 게이지**: 탄을 하나 벨 때마다 1칸 사용 (최대 4칸, 1.6초마다 1칸 회복), 게이지가 없으면 탄을 못 벤다 | 검기 날리기 | 일섬 |
| 토끼 도적 | 일반 (기본) | **부메랑 단검**: 가장 가까운 적 쪽으로 던지고, 날아갔다 돌아오며 갈 때와 올 때 두 번 맞힌다 | 급소 찌르기 | 그림자 단검 폭풍 |
| 곰 대장장이 | 희귀 | **망치 투척**: 가장 가까운 적을 향해 포물선으로 던지고, 떨어진 자리에서 폭발 | 대폭발 | 대지 강타 |
| 부엉이 비행사 | 영웅 | **회오리**: 천천히 나아가며 닿은 적을 계속 때리고 적 탄을 날려 버린다. 회오리 하나당 5발까지, 보스와 중간 보스의 탄은 못 막는다 | 폭풍 | 회오리 바람 |
| 고양이 마법사 | 전설 | **유도 마법 구슬**: 적을 따라간다. 패시브 **마력 보호막**: 8초마다 피해를 한 번 막는 보호막이 생긴다 | 분열 구슬 | 별빛 마법진 |

궁극기 (X 키 / 궁극기 버튼, 쓰는 동안 무적):

| 궁극기 | 효과 |
|---|---|
| 일섬 (여우) | 화면 끝까지 돌진한 뒤 지나간 가로줄을 통째로 벤다. 줄 안의 적에게 큰 피해, 화면의 탄 제거 |
| 그림자 단검 폭풍 (토끼) | 그림자 분신 4명이 3초 동안 적에게 유도 단검을 쏟아붓고, 분신 주변 탄을 막는다 |
| 대지 강타 (곰) | 바위 기둥 8개가 앞으로 차례로 솟는다. 땅의 적에게 특히 강하다 |
| 회오리 바람 (부엉이) | 3.5초 동안 거대한 회오리가 적과 탄을 빨아들이며 계속 피해 |
| 별빛 마법진 (고양이) | 적 탄을 코인으로 바꾸고, 3초 동안 별똥별을 떨어뜨린다. 마법진이 탄을 막는다 |

뽑기 (`RD.GACHA`):

- 1회 150 코인, 10회 1350 코인(희귀 이상 1개 보장). 처음 시작하면 600 코인을 준다.
- 확률: 전설 2.5%, 영웅 8%, 희귀 22%, 일반 67.5%. 50회 안에 전설이 안 나오면 다음 뽑기는 전설 확정.
- 이미 가진 캐릭터가 나오면 **각성**(★ +1): 위력 +6%, 최대 체력 +6. 최대 ★6, 그 뒤로는 코인 50을 돌려받는다.
- 코인은 게임에서 모은다: 코인 1, 보석 2, 별 8, 중간 보스 25, 보스 60 (`RD.COIN_VALUE`).
- 보유 캐릭터, 코인, 전설 확정 횟수는 브라우저에 저장된다.

## 소리

`src/audio.js`. 음악 파일 없이 Web Audio로 칩튠 소리를 만든다. 브라우저 정책 때문에 처음 화면을 누르거나 키를 누른 뒤부터 소리가 난다.

- 배경음악: 메뉴, 스테이지, 보스전 3곡 (`TRACKS`에서 음표와 템포를 바꿀 수 있다)
- 효과음: 캐릭터별 공격음, 피격, 처치, 폭발, 아이템, 레벨업, 캐릭터별 궁극기, 보스 경고, 클리어, 뽑기 등 (`SFX`)

## 밸런스 조절

숫자는 대부분 `src/data.js`에 있다.

- `RD.CONFIG`: 이동 속도, 체력, 피해량, 피격 판정 크기(`hitRadius`), 폭탄, 터치 감도
- `RD.DIFFICULTY`: 난이도별 배율, `RD.MODES`: 모드
- `RD.UPGRADES`: 강화 목록과 최대 단계 (효과 수치는 `src/game.js`의 능력치 계산과 `updateSubWeapons`)
- `RD.CHARACTERS[].shot`: 샷 간격(`cd`), 위력(`dmg`), 파워별 탄 배치(`lanes`)
- `RD.ENEMIES`: 적 체력과 점수
- `RD.BULLET.speed`: 적 탄속
- 스테이지 모드 등장 순서는 `src/game.js`의 `STAGE` 표, 무한/타임 어택의 무작위 패턴은 `PATTERNS`, 적 탄막 패턴은 `updateEnemies`

강화를 무작위로 고르는 회피 봇으로 시뮬레이션했을 때(보통), 첫 중간 보스는 약 10~25초, 첫 보스는 약 30~60초 걸린다.

## 구조

```
index.html              진입점
src/data.js             밸런스 값, 캐릭터·적·아이템 정의
src/sprites.js          임시 도트 캐릭터와 몬스터 (코드로 그림)
src/game.js             게임 로직 (스테이지 진행표, 적 패턴, 탄, 아이템, 폭탄)
src/render.js           화면 그리기
src/main.js             화면 전환, 입력, 게임 루프
assets/raw/             AI로 생성한 원본 이미지
assets/game/            게임에서 쓰는 가공된 PNG
tools/process_assets.py 원본 → 게임용 PNG 변환 (배경 제거, 자르기)
```

## 에셋 작업

```bash
python3 tools/process_assets.py
```

- 새 이미지는 `#FF00FF` 마젠타 배경으로 생성해서 `assets/raw/`에 넣고, `CROPS` 표에 `"magenta"` 모드로 추가한다.
- 캐릭터는 아직 코드로 그린 임시 도트(`src/sprites.js`)다. 진짜 스프라이트 시트가 생기면 `RD.getCharacterFrame`이 PNG 프레임을 돌려주도록 바꾸면 된다.
