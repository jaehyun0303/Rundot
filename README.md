# Rundot

텐가이, 1945 같은 오락실 2D 도트 슈팅 게임. 판타지 숲의 소동물 모험단이 가로로 흘러가는 숲 위를 날며 몬스터 편대와 탄막을 뚫고 보스를 잡는다.

## 실행

ES 모듈이나 빌드 도구 없이 순수 JavaScript + Canvas로 만들었다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

## 모드와 난이도

| 모드 | 내용 |
|---|---|
| 스테이지 | 스테이지 3개. 각 스테이지에 중간 보스(돌 골렘)와 보스(박쥐 왕). 3스테이지 보스를 잡으면 클리어 |
| 무한 | 무작위 편대가 끝없이 나오고 점점 강해진다. 80초마다 중간 보스, 두 번째마다 박쥐 왕 |
| 보스 러시 | 처음에 강화 3개를 고르고 중간 보스와 보스를 번갈아 상대 |
| 타임 어택 | 3분 동안 최대 점수 |

| 난이도 | 잔기 | 적 체력 | 탄속 | 적 공격 빈도 | 받는 피해 | 점수 |
|---|---|---|---|---|---|---|
| 쉬움 | 5 | x0.7 | x0.8 | x0.7 | x0.6 | x0.5 |
| 보통 | 3 | x1 | x1 | x1 | x1 | x1 |
| 어려움 | 3 | x1.35 | x1.2 | x1.35 | x1.4 | x1.6 |
| 지옥 | 2 | x1.8 | x1.4 | x1.8 | x2 | x2.5 |

최고 점수는 모드와 난이도마다 따로 저장된다.

## 규칙

- **체력**: 최대 100. 탄에 맞으면 18, 적과 부딪히면 28 깎인다(난이도 배율 적용). 맞은 뒤 0.9초 무적. 체력이 0이 되면 잔기 하나를 잃고 체력을 모두 채워 다시 나온다.
- 판정은 캐릭터 가운데의 **빨간 점**. 그림이 스치는 건 괜찮다.
- **하트**: 체력 30 회복. 적이 가끔 떨어뜨리고, 도깨비불과 보스는 자주 떨어뜨린다.
- **경험치와 레벨업**: 적을 잡으면 경험치가 쌓이고, 레벨이 오르면 게임이 멈추고 **강화 카드 3장 중 하나를 고른다**. 3장 중 하나는 꼭 주무기나 전용 강화다.
- **P**: 경험치 덩어리. 편대를 전부 잡거나 도깨비불을 잡으면 나온다.
- **B**: 폭탄 +1. 폭탄은 적 탄을 지우고 적 전체에 피해, 잠깐 무적.
- 15만 점마다 잔기 +1.

## 강화 (18종)

| 분류 | 강화 |
|---|---|
| 주무기 | 탄 추가(3, 캐릭터마다 이름과 효과가 다름: 베기 강화, 단검 추가, 망치 추가, 회오리 추가, 구슬 추가), 위력 강화(5), 연사 속도(5), 관통(2, 고양이만) |
| 전용 | 캐릭터마다 다름(3): 검기 날리기, 급소 찌르기, 대폭발, 폭풍, 분열 구슬 |
| 보조무기 | 유도 미사일(5), 레이저(5), 수호 구슬(4, 탄도 막음), 후방 사격(4), 번개(5), 펫 강화(4) |
| 능력 | 최대 체력(5), 자연 회복(3), 갑옷(3), 날개(3), 자석(3), 폭탄 상자(3), 행운(3) |

괄호는 최대 단계. 키보드로는 1/2/3 키나 ←→ + Enter로 고른다.

## 적

| 적 | 움직임 | 공격 |
|---|---|---|
| 박쥐 | 편대로 날아옴 (물결, 직선, 돌진) | 조준탄 1발 |
| 도깨비불 | 날아와서 잠시 멈춤 | 원형 탄막 |

| 독버섯 | 땅에 서 있음 | 3갈래 탄 |
| 돌 골렘 (중간 보스) | 땅에서 버팀 | 부채꼴 탄, 바위 포탄 |

## 캐릭터와 뽑기

여우와 토끼는 처음부터 가지고 있고, 나머지는 **캐릭터 뽑기**로 얻는다.

| 캐릭터 | 등급 | 공격 방식 | 전용 강화 | 궁극기 |
|---|---|---|---|---|
| 여우 견습기사 | 일반 (기본) | **근접 베기**: 앞쪽 부채꼴을 벤다. 베기에 닿은 적 탄은 사라진다. 파워 3부터 위아래 두 번 | 검기 날리기 | 일섬 |
| 토끼 도적 | 일반 (기본) | **부메랑 단검**: 날아갔다 돌아오며 갈 때와 올 때 두 번 맞힌다 | 급소 찌르기 | 그림자 단검 폭풍 |
| 곰 대장장이 | 희귀 | **망치 투척**: 가장 가까운 적을 향해 포물선으로 던지고, 떨어진 자리에서 폭발 | 대폭발 | 대지 강타 |
| 부엉이 비행사 | 영웅 | **회오리**: 천천히 나아가며 닿은 적을 계속 때리고 적 탄을 날려 버린다 | 폭풍 | 회오리 바람 |
| 고양이 마법사 | 전설 | **유도 마법 구슬**: 적을 따라간다 | 분열 구슬 | 별빛 마법진 |

궁극기 (X 키 / 궁극기 버튼, 쓰는 동안 무적):

| 궁극기 | 효과 |
|---|---|
| 일섬 (여우) | 화면 끝까지 돌진한 뒤 지나간 가로줄을 통째로 벤다. 줄 안의 적에게 큰 피해, 화면의 탄 제거 |
| 그림자 단검 폭풍 (토끼) | 그림자 분신 4명이 3초 동안 적에게 유도 단검을 쏟아붓고, 분신 주변 탄을 막는다 |
| 대지 강타 (곰) | 바위 기둥 8개가 앞으로 차례로 솟는다. 땅의 적에게 특히 강하다 |
| 회오리 바람 (부엉이) | 3.5초 동안 거대한 회오리가 적과 탄을 빨아들이며 계속 피해 |
| 별빛 마법진 (고양이) | 적 탄을 코인으로 바꾸고, 3초 동안 별똥별을 떨어뜨린다. 마법진이 탄을 막는다 |

뽑기 (`RD.GACHA`):

- 1회 150 코인, 10회 1350 코인(희귀 이상 1개 보장). 처음 시작하면 600 코인을 준다.
- 확률: 전설 2.5%, 영웅 8%, 희귀 22%, 일반 67.5%. 50회 안에 전설이 안 나오면 다음 뽑기는 전설 확정.
- 이미 가진 캐릭터가 나오면 **각성**(★ +1): 위력 +6%, 최대 체력 +6. 최대 ★6, 그 뒤로는 코인 50을 돌려받는다.
- 코인은 게임에서 모은다: 코인 1, 보석 2, 별 8, 중간 보스 25, 보스 60 (`RD.COIN_VALUE`).
- 보유 캐릭터, 코인, 전설 확정 횟수는 브라우저에 저장된다.

## 밸런스 조절

숫자는 대부분 `src/data.js`에 있다.

- `RD.CONFIG`: 이동 속도, 체력, 피해량, 피격 판정 크기(`hitRadius`), 폭탄, 터치 감도
- `RD.DIFFICULTY`: 난이도별 배율, `RD.MODES`: 모드
- `RD.UPGRADES`: 강화 목록과 최대 단계 (효과 수치는 `src/game.js`의 능력치 계산과 `updateSubWeapons`)
- `RD.CHARACTERS[].shot`: 샷 간격(`cd`), 위력(`dmg`), 파워별 탄 배치(`lanes`)
- `RD.ENEMIES`: 적 체력과 점수
- `RD.BULLET.speed`: 적 탄속
- 스테이지 모드 등장 순서는 `src/game.js`의 `STAGE` 표, 무한/타임 어택의 무작위 패턴은 `PATTERNS`, 적 탄막 패턴은 `updateEnemies`

강화를 무작위로 고르는 회피 봇으로 시뮬레이션했을 때(보통), 첫 중간 보스는 약 10~25초, 첫 보스는 약 30~60초 걸린다.

## 구조

```
index.html              진입점
src/data.js             밸런스 값, 캐릭터·적·아이템 정의
src/sprites.js          임시 도트 캐릭터와 몬스터 (코드로 그림)
src/game.js             게임 로직 (스테이지 진행표, 적 패턴, 탄, 아이템, 폭탄)
src/render.js           화면 그리기
src/main.js             화면 전환, 입력, 게임 루프
assets/raw/             AI로 생성한 원본 이미지
assets/game/            게임에서 쓰는 가공된 PNG
tools/process_assets.py 원본 → 게임용 PNG 변환 (배경 제거, 자르기)
```

## 에셋 작업

```bash
python3 tools/process_assets.py
```

- 새 이미지는 `#FF00FF` 마젠타 배경으로 생성해서 `assets/raw/`에 넣고, `CROPS` 표에 `"magenta"` 모드로 추가한다.
- 캐릭터는 아직 코드로 그린 임시 도트(`src/sprites.js`)다. 진짜 스프라이트 시트가 생기면 `RD.getCharacterFrame`이 PNG 프레임을 돌려주도록 바꾸면 된다.
