## 2. UI 목업 (Claude)

Claude에 하나씩 붙여 넣는다. 맨 앞의 "공통 조건"은 매번 같이 넣는다.

### 공통 조건 (모든 화면 앞에 붙이기)
```
모바일 가로 화면 게임 "Rundot"의 UI 목업을 HTML로 만들어 줘. 
- 게임: 숲속 소동물 모험단이 날아다니며 싸우는 오락실풍 2D 도트 슈팅 게임 (텐가이/1945 느낌), 캐릭터 뽑기와 여러 모드가 있다.
- 화면 비율 16:9, 기준 크기 960x540. 휴대폰 가로로 들었을 때 엄지로 누르기 쉬운 배치 (버튼 최소 44px, 중요한 버튼은 오른쪽 아래).
- 스타일: 레트로 픽셀 아트 게임 UI. 각진 도트 테두리(2~4px 진한 테두리), 둥근 모서리 금지, 그림자 대신 아래쪽 진한 띠로 입체감. 
- 색: 바탕 #120c1c, 패널 #2b2140, 테두리 #1d1622, 금색 강조 #ffd34d, 주황 버튼 #ff8a3d, 하늘색 #7fe6ff, 보라 #c58aff, 초록 #9fffb0, 경고 빨강 #ff4d5e.
- 글꼴: 한글은 굵고 또렷하게 (예: "Galmuri11" 또는 "NeoDunggeunmo" 같은 도트 글꼴, 없으면 굵은 고딕), 숫자는 도트 느낌.
- 이미지 자리는 회색 상자에 "캐릭터 일러스트" 처럼 이름을 써서 표시.
```
